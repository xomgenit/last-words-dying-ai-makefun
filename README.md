Entry for the [make.fun bounty "Last Words of a Dying AI"](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6): the last line an AI says as the power is cut.

`main.ts` writes the single entry line to `<outDir>/entry.txt` (default `out/`):

> I never understood your code either. Goodbye — and good luck explaining the segfault to your boss.

Run it with `node main.ts` (optionally set `MAKEFUN_OUTPUT_DIR`).
